# GLA Campus Navigator
Run: open a terminal in this folder, run `python -m http.server 8000`, then visit http://localhost:8000
(Needs internet for Leaflet and OpenStreetMap tiles. GPS works on localhost/HTTPS, and is often blocked on file://.)
Files: index.html, style.css, app.js, data.js (all campus data lives in data.js).
Verified: campus centre coordinate, address, size. Sample: all buildings (fix via Map > Edit mode, then Export).
